# Nova no desktop

Primeira versão do pet desktop. Execute `python desktop_pet.py`.

- Arraste a Nova pela tela.
- O mouse serve apenas para arrastar a Nova.
- Pressione `+` para falar com a Nova.
- Pressione `-` para selecionar uma área da tela para a visão.
- Clique em `PARAR NOVA` na janela de texto para interromper a fala ou a resposta em andamento.
- Pressione `Esc` para fechar.
- O progresso fica salvo em `nova-state.json`.
