# Nova Core

Camada independente das regras de evolução. Não depende de Ollama, áudio, navegador ou Steam.

## Eventos iniciais

- `conversation`: aumenta sociabilidade e atenção.
- `study`: aumenta inteligência e curiosidade.
- `creative-work`: aumenta criatividade e diversão.
- `care`: recupera fome, energia e atenção.
- `rest`: recupera descanso e energia.

O estado é salvo como JSON, permitindo backup, exportação e futura troca controlada de itens sem misturar memórias privadas.
