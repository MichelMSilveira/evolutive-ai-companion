# EnglishFlow

EnglishFlow is a portfolio-ready browser prototype for practicing professional English conversations. It focuses on realistic client discovery calls for automation and software projects.

## Features

- Voice input using the browser Web Speech API when supported
- English prompts with Portuguese translations displayed on screen
- Helpful phrase cards for scope, tools, and delivery conversations
- Responsive dark SaaS-style interface
- No API keys in the frontend; AI responses can be connected through a secure backend later

## Run locally

Open `index.html` in a modern browser. For microphone permissions, use a local server such as VS Code Live Server or any static development server.

This is a portfolio demo, not a production AI service. The next production milestone would add a backend for secure model calls, authentication, saved sessions, and real-time audio responses.
